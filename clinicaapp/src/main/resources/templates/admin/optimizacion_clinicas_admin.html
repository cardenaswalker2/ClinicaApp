Modelo Matemático Formal
1. Variables de Decisión Binarias:
\[ X_i = \begin{cases} 1, & \text{si se selecciona la clínica } i \\ 0, & \text{en caso contrario} \end{cases} \]
2. Función Objetivo (Minimizar Distancia):
\[ \text{Min } Z = \sum_{i=1}^{n} d_i X_i \]
3. Restricciones:
• Selección Única: \(\sum X_i = 1\)
• Radio Máximo: \(d_i X_i \le D_{max}\)
• Disponibilidad: \(X_i \le A_i, A_i \in \{0,1\}\)
• No Negatividad y Binariedad: \(X_i \in \{0,1\}, d_i \ge 0\) (Haversine)
4. Distancia Geodésica de Haversine (\(d_i \ge 0\)):
\[ a = \sin^2\left(\frac{\Delta lat}{2}\right) + \cos(lat_1)\cos(lat_2)\sin^2\left(\frac{\Delta lon}{2}\right) \] \[ d = 2R \cdot \text{atan2}\left(\sqrt{a}, \sqrt{1-a}\right) \ge 0 \]
