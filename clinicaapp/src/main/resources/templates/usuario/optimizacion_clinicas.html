Formulación Matemática del Modelo
1. Variables de Decisión Binarias

Se define una variable de decisión binaria para cada clínica evaluada \(i \in \{1, \dots, n\}\):

\[ X_i = \begin{cases} 1, & \text{si se selecciona la clínica } i \\ 0, & \text{en caso contrario} \end{cases} \]
2. Función Objetivo

Minimizar la distancia total recorrida por el usuario hasta la clínica seleccionada:

\[ \text{Min } Z = \sum_{i=1}^{n} d_i X_i = d_1 X_1 + d_2 X_2 + \dots + d_n X_n \]
Min Z = 2.4·X1 + 5.1·X2 + ...
3. Restricciones del Sistema
a) Unicidad de Selección:

Se debe seleccionar exactamente una sola clínica veterinaria:

\[ \sum_{i=1}^{n} X_i = 1 \]
b) Radio Máximo de Cobertura:

No seleccionar clínicas que superen el radio \(D_{max}\):

\[ d_i X_i \le D_{max}, \quad \forall i \]
c) Disponibilidad y Operatividad:

Solo clínicas aprobadas y abiertas (\(A_i = 1\)):

\[ X_i \le A_i, \quad A_i \in \{0, 1\} \]
d) Condición de No Negatividad y Binariedad:

Garantía de distancia positiva (\(d_i \ge 0\)) mediante Haversine y variables binarias:

\[ X_i \in \{0, 1\}, \quad d_i \ge 0, \quad \forall i \]
4. Cálculo Geodésico de Haversine (\(d_i \ge 0\))

Garantiza que la distancia física entre \((lat_1, lon_1)\) y \((lat_2, lon_2)\) nunca sea negativa:

\[ a = \sin^2\left(\frac{\Delta lat}{2}\right) + \cos(lat_1)\cos(lat_2)\sin^2\left(\frac{\Delta lon}{2}\right) \] \[ d = 2R \cdot \text{atan2}\left(\sqrt{a}, \sqrt{1-a}\right) \ge 0 \]
