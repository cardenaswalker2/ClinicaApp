1. Introducción

1.1 ¿Qué es ClinicApp?

ClinicApp es una plataforma web integral de salud digital (e-Health) diseñada para revolucionar la interacción entre pacientes, profesionales médicos y la administración clínica. Combina la gestión médica tradicional con capacidades avanzadas de Inteligencia Artificial para ofrecer diagnósticos predictivos y una experiencia de usuario excepcional.

1.2 ¿Para qué sirve?

Sirve como un ecosistema centralizado donde los pacientes pueden gestionar sus citas, consultar historiales y aprender sobre salud; los médicos pueden administrar diagnósticos asistidos por IA; y los administradores pueden gestionar la operatividad del centro de salud de forma eficiente.

¿Qué problema resuelve?

El sector salud frecuentemente sufre de sistemas fragmentados, tiempos de espera prolongados, falta de educación en salud para el paciente y diagnósticos tardíos. ClinicApp resuelve esto unificando los procesos, automatizando la comunicación y empoderando el diagnóstico médico con modelos predictivos de Machine Learning.

2. Objetivos

2.1 Objetivo General

Desarrollar e implementar una plataforma médica integral, segura e inteligente que optimice la gestión clínica, mejore la experiencia del paciente y asista a los profesionales de la salud mediante herramientas predictivas de Inteligencia Artificial.

2.2 Objetivos Específicos

Digitalizar

Los procesos de agendamiento y gestión de historias clínicas de forma rápida y segura.

Implementar IA

Modelos de Machine Learning para predecir posibles riesgos de salud basados en síntomas.

Fidelizar

Educar a los usuarios a través de un sistema interactivo (Quiz) con recompensas premium.

Garantizar

La seguridad de los datos médicos mediante protocolos de encriptación y OAuth2.

3. Descripción General del Sistema

3.1 Explicación de la Plataforma

ClinicApp es una aplicación basada en arquitectura cliente-servidor construida sobre el ecosistema Java (Spring Boot) con persistencia NoSQL. La plataforma se divide en portales de acceso según el rol del usuario (Paciente, Médico, Administrador), garantizando flujos de trabajo especializados para cada perfil.

3.2 Flujo General

Al ingresar, el sistema enruta al usuario según su nivel de acceso:

  • Flujo del Paciente: Registro, agendamiento de citas, visualización de historial, participación en campañas interactivas (Quiz de salud).
  • Flujo del Médico: Revisión de agendas, carga de historias clínicas, ejecución de algoritmos de soporte diagnóstico (Weka IA).
  • Sistema de Recompensas: Un módulo de fidelización integrado con un servidor de correos para emitir cupones digitales premium a los pacientes.

4. Funcionalidades Principales

  • Dashboard Personal: Resumen de citas próximas e historial médico.
  • Sistema Interactivo (Quiz): Evaluaciones dinámicas de 5 preguntas aleatorias con feedback visual que otorgan cupones de descuento.
  • Gestión de Recompensas: Envío automático de cupones digitales premium por correo electrónico con códigos de barras.

  • Agenda Inteligente: Gestión de turnos y visualización rápida del estado de los pacientes.
  • Soporte Diagnóstico: Interfaz de evaluación de síntomas conectada al motor de Machine Learning.

  • Notificaciones Automáticas: Integración con servicio de Email para confirmación de citas y envío de premios.
  • Gestión de Usuarios: Panel de control de roles y permisos.

5. Arquitectura del Sistema

La arquitectura de ClinicApp sigue el patrón MVC (Model-View-Controller) y una arquitectura de N capas para asegurar mantenibilidad y escalabilidad:

Presentación

Thymeleaf, HTML5, CSS3 Glassmorphism, JS (Web Audio API, LocalStorage).

Control

Controladores RESTful que exponen los endpoints y manejan peticiones HTTP.

Negocio

Lógica de negocio encapsulada (IEmailService, WekaPredictionService).

Persistencia

Spring Data MongoDB para interactuar con bases de datos NoSQL.

6. Tecnologías Utilizadas

Java & Spring Boot Framework principal que garantiza robustez y despliegue rápido.
Spring Security & OAuth2 Para autenticación segura y control de acceso basado en roles.
JavaMailSender Para el envío dinámico de correos electrónicos interactivos en HTML.
Thymeleaf & UI Moderno Bootstrap 5, animaciones e interactividad del lado del cliente.
MongoDB Base de datos orientada a documentos, ideal para historias clínicas.

7. Inteligencia Artificial y Machine Learning

ClinicApp no es un software médico convencional; es una plataforma verdaderamente inteligente.

Predicción con Weka

El sistema carga archivos .model pre-entrenados con datasets clínicos (.arff) para evaluar instantáneamente los signos vitales y síntomas ingresados por el médico, proporcionando una segunda opinión algorítmica y alertando sobre posibles patologías antes de que se agraven.

8. Seguridad y Privacidad

  • Protección de Datos Sensibles: Uso de protocolos de encriptación para contraseñas (BCrypt) y datos clínicos, cumpliendo con estándares de privacidad en salud.
  • Autenticación Moderna: Implementación de OAuth2 y filtros de Spring Security (SecurityFilterChain) para asegurar endpoints.

9. Diseño UI/UX

La interfaz fue diseñada bajo los principios de Modern Web Design:

  • Estética Premium: Uso de paletas de colores armoniosas, sombras suaves, y efectos glassmorphism.
  • Gamificación UI: El módulo de "Quiz" incorpora animaciones en tiempo real, efectos de sonido (Web Audio API) y generación visual de tickets tipo "Boarding Pass".
  • Responsive Design: Totalmente adaptable a dispositivos móviles, tablets y monitores de escritorio.

10. Metodología de Desarrollo

El proyecto se desarrolla utilizando principios de Metodologías Ágiles (Scrum / Kanban):

  • Iteración Continua: Entregas modulares e incrementales.
  • Pruebas (Testing): Validación constante mediante la suite de tests de Spring Boot (mvn test), asegurando calidad en integraciones como el EmailService.
  • Control de Versiones: Manejo estructurado de código fuente.
